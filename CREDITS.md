# Credits and licensing

Every visible frame in a generated video is a pre-existing asset from a stock
library. Nothing is AI-generated.

## Background footage — Pexels

Clips come from the [Pexels API](https://www.pexels.com/api/) under the
[Pexels licence](https://www.pexels.com/license/): free for commercial use, no
attribution required, though Pexels asks that you credit contributors where you
can. This app does: each render records `Video by <contributor> on Pexels` with
a link, shown in the chat under "Credits & how it was made".

[Pixabay](https://pixabay.com/service/license-summary/) is the second library,
used when Pexels returns nothing for a query. Same terms.

## Stickers — GIPHY

Animated stickers come from the [GIPHY API](https://developers.giphy.com/)
`/v1/stickers/search` endpoint, used under the
[GIPHY API Terms of Service](https://support.giphy.com/hc/en-us/articles/360020027752-GIPHY-API-Terms-of-Service).
GIPHY requires attribution ("Powered By GIPHY") for production use; the
per-video credits name the sticker's uploader where GIPHY provides one.

Uploaders retain rights to their stickers. For anything beyond a demo, obtain a
production key and follow GIPHY's attribution requirements.

## Audio — original

The tracks in `audio/` were **written for this project** by
`scripts/make-audio.ts`, which synthesises them from scratch. They are not
sampled from, derived from, or trained on any existing recording, so there is
no third-party rights holder.

This is deliberate. Real "trending audio" — the TikTok sense of the phrase — is
not legally or technically obtainable through any public API. Shipping a
committed, self-authored library is the honest version of that requirement: it
never 404s, needs no key, and cannot get the project into a licensing problem.

To use real licensed music instead, drop mp3s into `audio/` and add them to
`audio/manifest.json` with a matching `vibe`. No code changes needed.

## Fixtures

Everything in `fixtures/` is generated by `scripts/make-fixtures.ts` and exists
so the render pipeline can be tested with no network and no API keys.
